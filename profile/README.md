# alexlavibe

Le code et les expériences derrière les vidéos de la chaîne **alexlavibe**.

Chaque épisode montre l'IA au travail : ici, on publie ce qu'elle a vraiment écrit, les scripts qui ont fabriqué les images, et de quoi tout refaire chez soi.

- le code tel qu'il a servi pour la vidéo, et comment le lancer ;
